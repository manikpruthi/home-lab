# Welcome Home Worker

A single-file [Cloudflare Worker](https://workers.dev/) that serves a guest Wi-Fi landing page: a QR
code that joins the network on one scan, tap-to-copy credentials, and a contact link. Designed to sit
behind an NFC tag — tap the sticker, land on this page, join the Wi-Fi.

## Features

- **One-scan join** — renders a `WIFI:S:<ssid>;T:WPA;P:<pass>;;` QR code, which iOS and Android both
  recognise natively. No app, no captive portal.
- **Tap to copy** — network name, password, and address copy to the clipboard with a toast
  confirmation; the password stays masked on screen.
- **Read-only extras** — Bluetooth speaker name, and a WhatsApp deep link for contacting the host.
- **Light / dark** — follows `prefers-color-scheme`, with a frosted-glass card layout.
- **Zero hardcoded values** — every personal detail arrives from Worker secrets/variables.

## Architecture

```text
   NFC tag / link
        |
        v
  ┌──────────────────┐        ┌──────────────────────┐
  │ Cloudflare Worker│  env   │ WIFI_SSID  WIFI_PASS │
  │  (single file)   │◄───────│ BT_NAME    HOME_ADDR │
  │    GET /         │        │ WHATSAPP_NUM         │
  └────────┬─────────┘        └──────────────────────┘
           │
           v
   server-rendered HTML
   (QR via api.qrserver.com)
```

The Worker has no database, no cron, and no state — every request re-renders from `env`.

## Prerequisites

- [Node.js](https://nodejs.org/) 18+ and npm
- A Cloudflare account with Workers enabled
- [`wrangler`](https://developers.cloudflare.com/workers/wrangler/) CLI (`npx wrangler` works without
  a global install)

## Quickstart

```bash
cd welcome-home-worker

npm install

# Local development (uses .dev.vars for values)
cp .dev.vars.example .dev.vars   # then fill in your values
npm run dev

# Deploy, then set the same five values in
# Dashboard → Worker → Settings → Variables and Secrets
npm run deploy
```

## Configuration

| Variable | Required | Purpose |
|---|---|---|
| `WIFI_SSID` | yes | Network name, displayed and encoded into the QR |
| `WIFI_PASS` | yes | Network password, encoded into the QR and tap-to-copy |
| `BT_NAME` | no | Bluetooth speaker name on the read-only row |
| `HOME_ADDR` | no | Postal address shown on the card |
| `WHATSAPP_NUM` | no | Digits only with country code; powers the `wa.me` link |

## Security notes

- The Wi-Fi password is **not secret** by design — anyone who can read the QR can join. Treat this page
  as the guest network's front door: put guests on an isolated SSID/VLAN, and rotate the password when
  a guest's access should end.
- The QR is generated by a third party (`api.qrserver.com`), so the SSID and password are sent to that
  service in the image URL. Self-host the QR generator if that is unacceptable.
- Set a WAF rule / rate limit on the hostname to blunt scraping, and keep the `*.workers.dev` route
  disabled so the branded hostname's rules cannot be bypassed.
- `env.*` values are interpolated into HTML at render time. They are operator-controlled, not
  user-controlled, so this is not an XSS vector — do not wire this template to a request body.
